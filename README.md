# 怪物夜未眠 · Monster Sleepless

一切从深夜开始：你陪一只睡不着的怪物熬过一夜，之后每晚回来。

轻量交互游戏，游戏性第一。失眠与健康科普只是剧情——这里没有检查、没有治疗，也不输出诊断。

> 这是故事，不是诊断；不舒服请找医生。

**在线玩**：<https://wsemilynss.github.io/monster-sleepless/>　｜　本地单文件：[`怪物夜未眠.html`](怪物夜未眠.html)（与 `index.html` 内容相同，需与 `assets/` 放在同一目录）

## 玩法

1. **午夜 0:00**：怪物敲门，睁着眼蹲在门口。给它起个名字，告诉它最怕什么（太亮 / 太吵 / 太冷 / 太热 / 太静）。
2. **熬过四个时段**：子夜 → 深夜 → 凌晨 → 黎明。每个时段几枚光点，点按捕捉，听怪物说一句话；每章最多 5 个光点，可以「跳过本章」，没做完不惩罚。黎明是一段心跳节拍小游戏（连拍 8 下它就合眼）。
3. **天快亮了**：日出过场，今晚来过的夜访客现形——灼热的影子 / 絮语者 / 饱胀的石头 / 冰凉的手 / 刺眼的光 / 隐形的重量；没有谁来则是山神。
4. **怪物日记**：一屏读完——访客、它的脾气、3 张小行动卡（选 1 件今晚的小事）、一则寓言，可保存日记卡（本机生成 PNG）。
5. **明晚再来**：再次打开显示「第 N 夜」。「今晚继续」是 2 分钟内的夜间小关：5 个光点 → 选 1 张哄睡卡 → 怪物回一句话 → 日记。「重新开始」从取名页完整再玩一夜（存档保留）。
6. **图鉴 · 徽章 · 进化**：六位访客的三层图鉴（一句话 / 志怪小卡 / 寓言，出现过才解锁）；夜晚型徽章；累计 3 / 7 / 15 夜进化并收到一则寓言。

## 存档（只在你的浏览器里）

| localStorage 键 | 内容 |
|---|---|
| `mm_save` | `{v,name,fear,element,nights,calm,streak,last,evo,visitors:{id:次数},dex:[id],badges:{id:tier}}`；读取时逐字段校验，损坏/缺字段自动补默认；入口「清除存档」可清空 |
| `mm_mute` | 音效开关 |
| `mm_motion` | 减少动效开关（未设置时跟随系统 `prefers-reduced-motion`） |

不上传任何数据，没有后端。旧版 `mm_night` 会自动迁移。

## 调试参数

| 参数 | 作用 |
|---|---|
| `?debugNight=N` | 假装现在是第 N 夜（虚拟存档：已熬过 N-1 夜，六位访客随夜数出现）；不读写真实存档。`N=3 / 7 / 15` 出日记时分别触发三次进化，`N=16` 图鉴全部解锁 |
| `?debugVisitor=heat\|whisper\|stone\|cold\|glare\|weight` | 强制今晚的访客，用来逐一检查六位访客 |
| `?lite=1` | 强制低配模式（DPR 1、少一路颗粒视频、关装饰层）；运行中持续掉帧也会自动进入 |

## 无障碍与低配

- 顶栏可关闭音效（♪）与动效（动效 ON/OFF）；跟随系统「减少动态效果」；关闭动效后光点不再漂移、镜头不再自转、不震动。
- 键盘：光点可 Tab 聚焦、Enter 捕捉；有焦点环、「跳到内容」链接；弹窗带 `role="dialog"`。
- 低端手机：手机/≤4 核默认只用 2 层颗粒视频；掉帧时自动切到 lite。

## 技术约束

- 单文件 `index.html`，无框架、无后端、零依赖；部署：GitHub Pages
- `assets/` 存放插画与视频；`怪物夜未眠.html` 是同一份页面的命名副本（发布时与 `index.html` 保持一致）

## 生命感研究（life-research.html）

[`life-research.html`](life-research.html) 是公开的新媒体视觉艺术与交互设计研究页，线上地址：<https://wsemilynss.github.io/monster-sleepless/life-research.html>。

- **主题**：屏幕媒介的生命感（animacy）与拟人化（anthropomorphism）的区别、共性、相邻概念，以及知觉、生物运动、发展心理、HCI/HRI、交互艺术、声音、游戏 NPC 和关系伦理的交叉证据。
- **可视化**：生命感 × 拟人化四象限、七透镜图、可调运动/节律/目标/响应/记忆标本、S1/S7/v4.1 雷达对照、历史截图与版本时间线。雷达数值是设计审阅启发式，不是玩家评分或心理量表。
- **实时关联**：本地每 2 秒、GitHub Pages 每 20 秒检查 `index.html`；在隔离沙箱中读取公开 `NIGHT` 数据并执行 `monsterLook()` 的虚拟样本，内存存储不接触玩家存档，不上传数据。
- **任务书边界**：公开研究页不读取明文或加密任务书。S7 是已实现的当前版本，v4/v4.1 是下一阶段提案，不能将提案读成已上线功能。
- **来源与复测**：26 项文献附 DOI 或机构链接、用途与适用边界；附 2×2 对照研究方案和可下载 Markdown 提纲，不声称已完成用户研究或验证睡眠效果。
- **无障碍**：支持键盘、减少动效、360px 布局与打印/PDF；关闭动效后仍保留静态信息和文字状态。

## 专业审阅台（review.html）

[`review.html`](review.html) 是给睡眠医学、心理、中医和社会环境背景审阅者用的“专业学科与剧情分析”页面，不面向玩家。

- **实时同步**：页面在隔离沙箱里运行 `怪物夜未眠.html`，读出真实的剧本数据（存储被替换成内存版，不会动玩家存档），同时读取任务书并更新其专业分析。两份文件一保存，页面就自动刷新。
  - 本地服务器：每 2 秒检查一次。
  - GitHub Pages：每 20 秒检查一次。
  - 用 `file://` 直接打开：点"连接本地文件夹"（Chrome / Edge）。
- **查看密码**：打开页面先输入查看密码（不区分大小写，请向项目负责人索取）。可以勾选"在这台设备上记住"，点"锁定"可以清除；已保存但失效的密码也会自动清除。密码不匹配与浏览器校验组件故障分别提示。
- **任务书加密发布**：
  - 明文 `lane-brief.md` 不进仓库。线上只发布加密的 `lane-brief.enc`（PBKDF2-SHA256 派生密钥，AES-256-CBC 加密，HMAC-SHA256 校验），输入密码后在浏览器里解密。
  - `auto-sync.ps1` 发现 `lane-brief.md` 有改动，会自动重新加密并发布。
  - 更换密码：`powershell -ExecutionPolicy Bypass -File review-lock.ps1 -SetPassword 新密码`。它会更新本地密钥 `review.key.json`（不提交）和 `review.html` 里的校验值，并重新加密任务书。
- **审阅内容**：
  - 手札卡、红旗、睡眠窗口、身体观察/四诊、行动建议、现实环境和证据边界都自动归类，并标注专业原理与出处。
  - 规则检查：诊断用语、药物与剂量、疗效承诺、具体卧床时长等；否定性安全边界不会被当成疗效承诺。
  - 全局安全检查、学科 × 剧情矩阵、证据链图、任务书 × 游戏实现对照。
- **任务书双版本专业对比**：每次任务书变化会自动在当前浏览器保存快照（最多 10 版，空间不足时减少），默认比较上一版和当前实时版；也可导入两份 Markdown。可视化包括学科与主题增减、新增/解除规则提示、E/T 来源标注覆盖及逐条前后区别，可导出对比报告。自动配对和分析只作审阅导航，不等于文献核验或专业审核。
- **审阅记录**：保存在审阅者自己的浏览器里，可导出 Markdown 报告或 JSON 记录，也可导入合并多位审阅者的意见。条目原文被修改后，原结论会自动转为"已改动 · 待复审"。
