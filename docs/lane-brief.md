## 0. 通用规则（每次派发都要带）

- 定位：轻量交互游戏，**游戏性第一**。剧情借鉴沉浸式戏剧《Sleep No More》，世界观是"山海经 × 上海石库门里弄"。玩家戴面具夜游里弄，跟踪不睡觉的怪物，找出它们睡不着的原因，帮它们安然睡去，然后收集它们。
- 知识是剧情：CBT-I（失眠认知行为疗法）+ 中医 + 生理 + 心理 + 营养。用故事口吻讲，**不诊断、不开处方、不给药物/保健品建议、不给具体卧床时长**。
- 保留架构：单文件、四时段 `NIGHT.phases`、光点舞台 `buildStage`/`captureOrb`、心跳小游戏 `enterPulse`、日记 `renderDiary`、图鉴 `renderDex`、存档 `mm_save`、徽章、进化、`FX` 音效、`?debugNight`/`?debugVisitor`/`?lite`。只新增或改写，不推倒重来。
- 一任务一 PR；每个 PR 合并后游戏能从头玩到尾；不拆文件、不加框架或后端、不上传数据。
- 文案用怪物口吻、志怪叙事；不对玩家用"你的身体"直问；没做好不惩罚；不显示健康分数或百分比。
- 免责声明保留："这是故事，不是诊断；不舒服请找医生。"红旗内容（4.4）出现时，暂停游戏化奖励并给出就医提示。

## 1. 现状诊断：为什么"剧情弱、无趣"

| 现象 | 代码原因 | 结果 |
|---|---|---|
| 只有一只怪物，访客只是结果 | `pickVisitor(state.weights)` 用权重算出访客，访客只在日出和日记里出场 | 玩家没有"追一个角色"的动机 |
| 四个时段是同一种操作 | 子夜/深夜/凌晨都是抓光点 → 答题环（`openOrb`/`focusQuestion`） | 没有冲突、转折和揭晓 |
| 问题仍是问卷 | `DISPLAY_Q` 只换了主语，题库还是舌象、二便、寒热 | 内容像体检 |
| 解决方式是随手选 | `RITUAL_CARDS` 三选一，选对只换一句台词 | 没有解谜快感 |
| 知识浅 | `VISITOR_CARDS` 每位只有三句 | 看不到失眠"为什么会持续"，缺 CBT-I 核心洞见 |
| 视觉单调 | 深色背景 + 光点 + 单张白描图 | 世界观不成立，没有"夜游"的空间感 |

**核心问题：** 现在是"一只怪物 + 一份问卷 + 一个结果"。要改成"一个世界 + 很多角色 + 每个角色一段可破解的循环"。

## 2. 新结构：借鉴《Sleep No More》

| Sleep No More | 夜游里弄 | 游戏机制 |
|---|---|---|
| 观众戴白面具、不能说话，自由游走 | 玩家领一张**夜游面具**，只能看、跟、拾物，不能直接发问 | 去掉对玩家自己的盘问；线索来自观察 |
| 多层建筑，每个房间都是布景 | **石库门里弄**：亭子间、后弄堂、灶披间、前楼、老虎灶、天井、晒台、熟食店、三层阁、屋脊、后厢房、前厢房、过街楼、更夫亭 | 里弄剖面图作为 Hub，每间屋住一只怪物 |
| 演员按固定路线循环，一晚演三遍 | 每只怪物每晚**重复同一段循环**（它的失眠习惯） | 第 1 遍看，第 2 遍改一件事，第 3 遍它睡着 |
| 跟着一个角色才看得到完整故事 | 选一扇亮着的窗，**跟踪一只怪物** | 非线性：先追谁自己定 |
| 一对一密室 | **密谈**：怪物把你拉进角落说出它的过去 | 揭示"素质/诱发"，并做一次认知重构 |
| 结尾所有人汇合 | **天亮早点摊**：睡着的怪物在梦里聚到弄堂口 | 收集进度可视化 |
| 摘下面具 | **揭下面具**（可选）：镜子里是自己 | 轻量自我投射，不强迫 |

### 2.1 一只怪物的一夜（复用四时段，每夜约 6–8 分钟）

| 时段 | 幕 | 玩法 | 复用 | 揭示 |
|---|---|---|---|---|
| 子夜 00:00 | **第一幕 · 跟随** | 怪物在 2–3 处走它的循环，玩家点亮 3–5 个**物件** | 光点舞台：光点变成物件，`captureOrb` 掉线索 | **维持因素**（每晚重复的习惯） |
| 深夜 02:00 | **第二幕 · 密谈** | 怪物说出念头；玩家从 3 张"另一种想法"卡里选 1 张 | `addAnswerNodes` | **诱发 + 素质**，加认知重构 |
| 凌晨 04:00 | **第三幕 · 改一件事** | 循环重演，玩家在房间里改 1 个物件，3 选 1 | 题目环 + 循环重播 | **CBT-I 工具** |
| 黎明 06:00 | **第四幕 · 哄睡** | 每只怪物一个专属小游戏，默认心跳节拍 | `enterPulse` 插件化 | 身体层面的放松 |
| 日出 | **收集** | 怪物睡着，变成睡着的志怪卡；可选"揭下面具"；带回现实一件小事 | `renderDiary`/`renderDex` | 跨学科四格 + 3P 卡 |

### 2.2 元结构："失眠的三根柱子"（3P 模型）
- **素质**（Predisposing）：它天生的样子，密谈中揭示。
- **诱发**（Precipitating）：哪件事让它开始睡不着，密谈中揭示。
- **维持**（Perpetuating）：每晚重复、让失眠延续的习惯，跟随中揭示。

CBT-I 的核心洞见是"**维持因素才是可以改的**"，所以第三幕永远只改维持因素。图鉴里有一块"三根柱子"总板，收集越多越能看清：能改的，大多在"维持"这一列。

### 4.2 单只怪物完整剧本模板（以 旁妮儿拉灯 Pianoland 为例，其他按同一格式补全）

## 5. 视觉与素材方案

### 5.1 美术方向
- **色调：** 墨黑 + 青砖灰 + 每只怪物一种霓虹色（扩展 `VCOLOR` 到 14 只）。
- **里弄空间：** 3–4 层 CSS 视差：远景石库门门头剪影（SVG）、中景（电线、晾衣绳、招牌、蒸汽）、近景窗框、雾。每间屋换中景布景。
- **面具视野：** 戴上面具后四周出现柔和的面具形暗角与呼吸感。`prefers-reduced-motion` 下静止。
- **怪物渲染：** 白描插画用 `filter: invert(1)` + `mix-blend-mode: screen` 变成黑底发光线稿，再用 `drop-shadow(怪物色)` 上色。醒着轻微漂浮和眨眼；睡着时降亮度，加呼吸起伏和"Zz"粒子。
- **收集卡：** 睡着的怪物变米色纸质卡（沿用日记卡 `paperArt` 风格），卡背是三根柱子 + 四格。
- **成对角色：** 幼年版/成年版、学徒版/本人，在收集卡上并排显示，已收集的一方亮，另一方剪影。

### 5.2 素材调用
- 14 个角色全部来自 `00.creatures-怪物角色`（仓库已有 13 张的优化版，缺 `喇巴菜菜子`，R0 压缩补入 `assets/ref/laxiaxia.webp`）。

    loop: {/* monsterId: {src:'ref/xxx.mp4', poster:'ref/xxx.jpg'} */}
