## 0. 通用规则（每次派发都要带）

- 定位：轻量交互游戏，**游戏性第一**。剧情借鉴沉浸式戏剧《Sleep No More》的结构，世界观是"山海经 × 上海石库门里弄"。玩家戴面具夜游里弄，跟踪不睡觉的怪物，找出它们睡不着的原因，帮它们安然睡去，然后收集它们。
- 知识是剧情：CBT-I（失眠认知行为疗法）+ 中医 + 生理 + 心理 + 营养。用故事口吻讲出来，**不诊断、不开处方、不给药物/保健品建议、不给具体卧床时长**。
- 保留架构：单文件、四时段 `NIGHT.phases`、光点舞台 `buildStage`/`captureOrb`、心跳小游戏 `enterPulse`、日记 `renderDiary`、图鉴 `renderDex`、存档 `mm_save`、徽章、进化、`FX` 音效、`?debugNight`/`?debugVisitor`/`?lite`。只新增或改写，不推倒重来。
- 一任务一 PR；每个 PR 合并后游戏能从头玩到尾；不拆文件、不加框架或后端、不上传数据。
- 文案用怪物口吻、志怪叙事；不对玩家用"你的身体"直问；没做好不惩罚；不显示健康分数或百分比。
- 免责声明保留："这是故事，不是诊断；不舒服请找医生。"红旗内容（第 4.4 节）出现时，暂停游戏化奖励并给出就医提示。
- 素材：原图不直接入库。压缩后放 `assets/ref/`（图 ≤ 300KB 的 webp/jpg，视频 ≤ 1.5MB、≤ 720p、无声、循环，附 poster）。
- 验证：`python3 -m http.server 8765`，浏览器实操，控制台无报错，桌面和 360px 宽都要检查，开启 `prefers-reduced-motion` 也要过一遍。PR 写明改动函数、验证步骤、截图。

## 1. 现状诊断：为什么"剧情弱、无趣"

| 现象 | 代码原因 | 结果 |
|---|---|---|
| 只有一只怪物，访客只是结果 | `pickVisitor(state.weights)` 用权重算出访客，访客只在日出和日记里出场 | 玩家没有"追一个角色"的动机，访客像一份报告 |
| 四个时段是同一种操作 | 子夜/深夜/凌晨都是抓光点 → 答题环（`openOrb`/`focusQuestion`），只是换了台词 | 没有戏剧推进，也没有冲突、转折和揭晓 |
| 问题仍是问卷 | `DISPLAY_Q` 把题目改成问怪物，但题库还是舌象、二便、寒热 | 换了主语，内容还是体检 |
| 解决方式是随手选 | `RITUAL_CARDS` 三选一，选对与否只换一句台词 | 没有"解谜成功"的快感 |
| 知识浅，没有底层结构 | `VISITOR_CARDS` 只有三句（志怪/现代/心里话） | 看不到失眠"为什么会持续"，缺 CBT-I 的核心洞见 |
| 视觉单调 | 深色背景 + 光点 + 单张白描图，各访客没有自己的空间 | 世界观不成立，缺"夜游"的空间感 |

**核心问题：** 现在是"一只怪物 + 一份问卷 + 一个结果"。要改成"一个世界 + 很多角色 + 每个角色一段可破解的循环"。

## 2. 新结构：借鉴《Sleep No More》

| Sleep No More | 夜游里弄 | 游戏机制 |
|---|---|---|
| 观众戴白面具、不能说话，自由游走 | 玩家在弄堂口领一张**夜游面具**，只能看、跟、拾物，不能直接发问 | 去掉对玩家自己的盘问；线索来自观察 |
| 多层建筑，每个房间都是布景 | **石库门里弄**：天井、客堂间、灶披间、亭子间、前楼、晒台、老虎窗、过街楼、老虎灶、熟食店 | 里弄地图作为 Hub，每间屋住一只怪物 |
| 演员按固定路线循环，一晚演三遍 | 每只怪物每晚**重复同一段循环**（它的失眠习惯） | 第 1 遍看，第 2 遍改一件事，第 3 遍它睡着 |
| 跟着一个角色才看得到完整故事 | 玩家选一扇亮着的窗，**跟踪一只怪物** | 非线性：先追谁自己定 |
| 一对一密室：演员拉你进小房间说秘密 | **密谈**：信任够了，怪物把你拉进角落，说出它的过去 | 揭示失眠的"素质因素/诱发事件" |
| 结尾所有人在宴会厅汇合 | **天亮早点摊**：睡着的怪物都在梦里聚到弄堂口；终章山神现身 | 收集进度可视化，终章汇合 |
| 摘下面具的那一刻 | **揭下面具**（可选）：镜子里照出的是自己 | 轻量自我投射，不强迫 |

### 2.1 一只怪物的一夜（复用现有四时段，每夜约 6–8 分钟）

| 时段 | 幕 | 玩法 | 复用 | 揭示 |
|---|---|---|---|---|
| 子夜 00:00 | **第一幕 · 跟随** | 怪物在 2–3 间屋里走它的循环；玩家跟着走，点亮 3–5 个**物件**（钟、手机、酒杯、纸条…） | 光点舞台：光点变成物件，`captureOrb` 掉落线索 | **维持因素**（每晚重复的习惯） |
| 深夜 02:00 | **第二幕 · 密谈** | 怪物说出它的念头，比如"今晚再睡不着，明天就完了"；玩家从 3 张"另一种想法"卡中选 1 张递过去 | 题目环 `addAnswerNodes` | **诱发事件 + 素质因素**，加上认知重构 |
| 凌晨 04:00 | **第三幕 · 改一件事** | 循环重演一遍，玩家在房间里改动 1 个物件（把钟转过去、把手机放门外…），3 个选项里找对应的 CBT-I 工具；选错时循环温和重演，并给提示 | 题目环 + 循环重播 | **CBT-I 工具** |
| 黎明 06:00 | **第四幕 · 哄睡** | 每只怪物一个专属小游戏，默认用心跳节拍 | `enterPulse` 改成插件式 | 身体层面的放松 |
| 日出 | **收集** | 怪物睡着，变成一张"睡着的志怪卡"收进图鉴；可选"揭下面具"；带回现实一件小事 | `renderDiary`/`renderDex` | 跨学科四格 + 3P 卡 |

### 2.2 元结构："失眠的三根柱子"（3P 模型）

每只怪物都有三条线索，对应 Spielman 3P 模型：
- **素质**（Predisposing）：它天生的样子，在密谈中揭示。
- **诱发**（Precipitating）：哪件事让它开始睡不着，在密谈中揭示。
- **维持**（Perpetuating）：每晚重复、让失眠延续的习惯，在跟随中揭示。

CBT-I 的核心洞见是"**维持因素才是可以改的**"，所以第三幕永远只改维持因素。图鉴里有一块"三根柱子"总板，收集越多，玩家越能看清：失眠的底层原因大多在"维持"这一列。

### 2.3 夜游手札（CBT-I 知识收集）

每收集一只怪物，掉落 1 张手札卡。集齐 10 张，就是一套完整的 CBT-I 科普：

| 卡 | 主题 | 故事化一句 |
|---|---|---|
| 1 | 睡眠两台发动机（睡眠驱力 + 生物钟） | "沙漏攒满了沙，钟又敲到了点，觉才会来。" |
| 2 | 刺激控制：床只留给睡眠 | "床记性很好，你在上面发愁，它就记住了发愁。" |
| 3 | 起床时间是锚 | "不管昨晚怎样，天亮就起，钟才不会乱。" |
| 4 | 睡眠窗口（睡眠限制的概念） | "躺得比睡得久，床就变成了雾泽。具体怎么调，要和专业的人一起来。" |
| 5 | 担忧时段 | "心事有自己的时间，不必挤在枕头上。" |
| 6 | 想法不是事实（认知重构） | "'睡不满八小时就完了'，只是一个念头。" |
| 7 | 身体放松（腹式呼吸、渐进式肌肉放松） | "先松肩，再松手，最后松开眉头。" |

### 4.2 单只怪物完整剧本模板（以烛宫鸦为例，其他怪物按同一格式补全）

**入场（亭子间，霓虹招牌作坊，墙上一排小灯泡）**
- 旁白：“亭子间的灯，从来没灭过。”
- 烛宫鸦（背对着你，嘴里衔着一颗火种）：“再看一会儿……就一会儿。”

**第一幕 · 跟随（子夜 00:00）**：它在三处之间绕圈：工作台 → 床 → 窗边。可拾取的物件（光点）：
1. **发光的手机**：“屏幕上的光，比月亮还亮。” → 维持：床上刷屏
2. **周末的闹钟（指着 11:30）**：“周末，它睡到中午才起。” → 维持：起床时间不固定
3. **工牌（印着夜班）**：“三个月前，它换了夜班。” → 诱发线索的预告
4. **窗帘（拉得严严实实）**：“它的早晨，从来照不进光。” → 维持：缺少早晨的光
5. **冷掉的浓茶**：“晚上九点泡的。” → 饮食起居
- 第一幕结束：“它又看了一眼钟。三点了。”

**第二幕 · 密谈（深夜 02:00）**：它把你拉进招牌后面的小角落。
- 烛宫鸦：“我生来就是夜里的鸟。白天，我的眼睛是灰的。”（素质）
- 烛宫鸦：“后来换了夜班。现在没夜班了，我的钟却回不去了。”（诱发）
- 烛宫鸦：“白天的时间都是别人的。只有半夜，是我自己的。”（念头）
- 递一张"另一种想法"卡（三选一，选错不扣分，只是换一句回应）：
  - ✔ “早上那一点光，也可以是你自己的。”
  - “那就熬吧，反正也睡不着。”
  - “你就是不够自律。”
- 选对时：它愣了一下：“……我没想过早上。”

**第三幕 · 改一件事（凌晨 04:00）**：循环重演。在房间里选一样东西改动：
- ✔ **把闹钟定在每天同一个时间，并拉开窗帘一条缝** → 手札卡 3 “起床时间是锚”
- 把手机调成夜间模式，继续刷 → 回应：“光是暗了，钟还是没停。”（循环重演）

## 5. 视觉与素材方案

### 5.1 美术方向
- **色调：** 墨黑 + 青砖灰 + 每只怪物一种霓虹色（沿用 `VCOLOR` 并扩展到 10 只）。
- **里弄空间：** 用分层视差（3–4 层 CSS 图层）：远景石库门门头剪影（SVG）、中景晾衣绳/电线/招牌、近景窗框、雾。每间屋子换中景布景即可，不用为每间屋画整张。
- **面具视野：** 戴上面具后，屏幕四周出现柔和的面具形暗角与轻微呼吸感（参照 SNM 的白面具）。`prefers-reduced-motion` 时静止。
- **怪物渲染：** 白描插画用 `filter: invert(1)` + `mix-blend-mode: screen` 变成黑底发光线稿，再用 `drop-shadow(怪物色)` 上色。醒着时有轻微漂浮和眨眼；睡着时降低亮度，加呼吸起伏和"Zz"粒子。
- **收集卡：** 睡着的怪物变成米色纸质卡（复用日记卡的 `paperArt` 风格），卡面是睡姿线稿，卡背是三根柱子 + 四格。
- **时段：** 沿用 `NIGHT.phases` 的色温、星点和颗粒变化；每只怪物的一夜都走一遍 00:00 → 06:00。

### 5.2 素材调用
- **现有 `assets/img`：** 10 只 BEASTS 作为怪物；`keyao` 作为守夜人；`pealk` 作为山神；`defo`（欲灵）作为面具商或镜中人；`yuling`、`lubu`、`cuicui`、`shanji`、`shanjiao` 可作里弄 NPC 或布景（R0 决定）。
- **Reference 文件夹：** 由 R0 盘点。建议用途：
  - 怪物动态视频 → 怪物 idle 循环（替换静态图，失败时退回静态图）
  - 场景或纹理视频 → 房间背景层，透明度低
  - 补充插画 → 睡姿、收集卡、物件图标
- **统一入口：** 新增 `ASSET` 映射表，所有图片和视频都从这里引用：
  ```js
  const ASSET = {
    img:  k => `assets/img/${k}.jpg`,
    ref:  k => `assets/ref/${k}`,          // R0 压缩后的 Reference 素材
    loop: {/* monsterId: {src:'ref/xxx.mp4', poster:'ref/xxx.jpg'} */}
  };
  ```
- **视频规则：** `muted loop playsinline preload="none"`，进入房间时才加载，离开时 `pause()`；`?lite=1` 或减少动效时只显示 poster。`reference-figures.mp4` 继续用作颗粒层。
- **声音：** 用现有 `FX`（WebAudio 合成）补充里弄环境音：远处钟声、老虎灶水开、晾衣绳风声、收音机杂音、雨打瓦片。不加音频文件。
